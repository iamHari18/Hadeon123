Number systems and codes

Q1Convert 156 (decimal) to binary, octal and hexadecimal.Easy

Divide by 2 repeatedly, or subtract powers of two: 156 = 128 + 16 + 8 + 4.

BaseValue
Binary1001 1100
Octal234 (group bits in threes from the right: 010 011 100)
Hex9C (group in fours: 1001 1100)

Grouping bits is the fastest route between binary, octal and hex; never go through decimal for those.

Q2What is two's complement and why is it used?Easy

To negate an n-bit number, invert all bits and add 1. An n-bit two's complement number covers −2n−1 to 2n−1 − 1 (8-bit: −128 to +127). It is used because addition and subtraction use the same adder hardware with no special case for sign, and there is only one representation of zero (unlike sign-magnitude and one's complement, which have +0 and −0).

Example: −45 in 8 bits. 45 = 0010 1101 → invert 1101 0010 → add 1 → 1101 0011.

Q3How do you detect overflow in two's complement addition?Medium

Overflow happens when two numbers of the same sign produce a result of the opposite sign. In hardware: overflow = carry into the MSB XOR carry out of the MSB. Adding two numbers of opposite signs can never overflow. Example (8-bit): 100 + 50 = 150, but 0110 0100 + 0011 0010 = 1001 0110 which reads as −106: overflow.

Q4What is Gray code and where is it used?Easy

In Gray code, consecutive values differ in exactly one bit. Binary to Gray: G = B ^ (B >> 1). It is used in rotary encoders (no false intermediate reading when several bits would change at once), in K-map ordering, and most importantly in asynchronous FIFO pointers: a pointer crossing a clock domain changes only one bit per step, so a synchroniser either samples the old value or the new one, never a corrupt mix.

Q5What is BCD, and how is BCD addition corrected?Easy

Binary-coded decimal stores each decimal digit in 4 bits (0000–1001). When adding two BCD digits, if the 4-bit sum is greater than 9 or a carry is produced, add 6 (0110) to skip the six unused codes and generate the decimal carry. Example: 7 + 6 = 1101 (13) → +0110 = 1 0011, which is BCD 13.

Logic gates and Boolean algebra

Q6Why are NAND and NOR called universal gates?Easy

Any Boolean function can be built using only NAND gates, or only NOR gates. With NAND: NOT A = NAND(A, A); AND = NOT(NAND); OR(A, B) = NAND(A′, B′). Universal gates matter in practice because in CMOS a NAND or NOR is a single compact stage, while AND and OR need an extra inverter. NAND is usually preferred over NOR because its series transistors are NMOS (fast), while NOR has series PMOS (slow, needs wider devices).

Q7State De Morgan's theorems.Easy

(A · B)′ = A′ + B′
(A + B)′ = A′ · B′

In words: break the bar and change the operator. A NAND gate is equivalent to an OR gate with inverted inputs (a "bubbled OR"), which is how you redraw circuits to convert between AND-OR and NAND-NAND.

Q8Write the truth-table behaviour of XOR and XNOR, and give uses of XOR.Easy

XOR outputs 1 when the inputs differ; XNOR outputs 1 when they are equal. Uses: the sum bit of an adder, parity generation and checking (XOR of all bits), controlled inverter (A XOR 1 = A′, A XOR 0 = A), comparators (XNOR for equality), Gray-code conversion, and CRC/LFSR feedback.

Q9How do you implement a 2-input XOR using only NAND gates? How many are needed?Medium

Four NAND gates:

  1. N1 = NAND(A, B)
  2. N2 = NAND(A, N1)
  3. N3 = NAND(B, N1)
  4. Y = NAND(N2, N3)

This works because N2 = A′ + B, N3 = A + B′ and NAND(N2, N3) = AB′ + A′B. Using NOR gates you need five.

Q10What are SOP and POS forms, and minterms versus maxterms?Medium

Sum of products (SOP): OR of AND terms, read from the rows where output is 1. Each full product term is a minterm, written Σm(...). Product of sums (POS): AND of OR terms, read from rows where output is 0; each full sum term is a maxterm, written ΠM(...). A function's minterm list and maxterm list are complementary: F = Σm(1,3,5) for three variables is the same as ΠM(0,2,4,6,7).

K-maps and minimisation

Q11Why are K-map cells ordered in Gray code?Easy

So that physically adjacent cells (including wrap-around at the edges) differ in exactly one variable. Grouping two adjacent 1s then eliminates the variable that changes, directly applying the identity AB + AB′ = A. Groups must be powers of two (1, 2, 4, 8) and as large as possible.

Q12Minimise F(A,B,C,D) = Σm(0, 2, 5, 7, 8, 10, 13, 15).Medium

Minterms 0, 2, 8, 10 are the four corners (B′D′). Minterms 5, 7, 13, 15 form a 2 × 2 block where B = 1 and D = 1 (BD).

F = B′D′ + BD = (B XNOR D)

Spotting XOR/XNOR patterns (checkerboard or diagonal groups) is a frequent follow-up in interviews.

Q13What are don't-care conditions and how are they used?Medium

A don't-care (X or d) is an input combination that never occurs or whose output does not matter, for example BCD inputs 1010–1111. In a K-map you may treat each X as 1 or 0, whichever gives larger groups; you do not have to cover them. Example: a BCD "digit ≥ 5" detector simplifies to A + BD + BC using don't-cares, instead of a much longer expression.

Q14What is a static hazard and how do you remove it?Hard

A static-1 hazard is a brief 0 glitch on an output that should stay 1 when one input changes, caused by two product terms being covered by different gates with different delays. In a K-map it shows up as two adjacent groups that do not overlap. Fix it by adding the consensus term: for F = AB + A′C, add BC, so F = AB + A′C + BC. The added term is logically redundant but covers the transition. In synchronous designs hazards in combinational logic are usually harmless because flip-flops only sample after the logic settles; they matter on asynchronous inputs such as clocks, resets and clock enables built from gates.

Combinational circuits

Q15Draw the logic of a half adder and a full adder.Easy

Half adder: Sum = A ⊕ B, Carry = A · B.

Full adder (with carry in Cin): = Sum = A ⊕ B ⊕ Cin = Cout = AB + Cin(A ⊕ B)

A full adder can be built from two half adders and an OR gate.

Q16Compare ripple-carry and carry-lookahead adders.Medium

In CLA, Ci+1 = Gi + PiCi, expanded so each carry is computed directly from inputs and C0, not from the previous stage.

Q17How do you build a 4:1 multiplexer, and why is a mux called a universal element?Easy

A 4:1 mux has inputs I0–I3, selects S1 S0: Y = S1′S0′I0 + S1′S0I1 + S1S0′I2 + S1S0I3. Any n-variable function can be implemented with a 2n:1 mux by tying inputs to 0/1, or with a 2n−1:1 mux by tying the data inputs to 0, 1, the last variable or its complement. That is why LUT-based FPGAs are essentially big multiplexers.

Q18Implement F(A,B,C) = Σm(1, 2, 6, 7) using a 4:1 mux.Medium

Use A, B as selects and express each data input in terms of C:

ABMintermsOutput in terms of CData input

01m2, m31, 0I1 = C′
10m4, m50, 0I2 = 0

Q19What is the difference between a decoder and a demultiplexer, and an encoder and a priority encoder?Easy

A decoder converts n inputs into one of 2n active outputs. A demux routes one data input to one of 2n outputs chosen by select lines; a decoder with an enable input acts as a demux, with the enable as data. An encoder does the reverse (2n lines to an n-bit code) but gives a wrong code if more than one input is active. A priority encoder outputs the code of the highest-priority active input and a valid flag, which is how interrupt controllers pick which request to serve.

Latches, flip-flops and counters

Q20What is the difference between a latch and a flip-flop?Easy

A latch is level-sensitive: while enable is high, the output follows the input (transparent). A flip-flop is edge-triggered: it samples the input only at a clock edge. A D flip-flop is commonly built as two latches in master–slave arrangement with opposite enables. Flip-flops are preferred in synchronous design because timing analysis is simpler; latches are smaller and allow time borrowing but make timing analysis harder, and unintended latches in HDL code are usually bugs.

Q21Write the characteristic equations of SR, JK, D and T flip-flops.Easy

DQ⁺ = DSimplest; used in almost all synchronous design

Q22What is the race-around condition and how is it avoided?Medium

In a level-triggered JK flip-flop with J = K = 1, the output toggles; if the clock stays high longer than the propagation delay, it toggles again and again, so the final state is unpredictable. It is avoided by making the clock pulse shorter than the delay (impractical), by using a master–slave JK, or by using edge-triggered flip-flops, which is what all modern designs do.

Q23Compare asynchronous (ripple) and synchronous counters.Medium

In a ripple counter, each flip-flop is clocked by the previous flip-flop's output, so delays add up: a 4-bit ripple counter settles after 4 flip-flop delays, and outputs pass through wrong intermediate values (decoding glitches). In a synchronous counter all flip-flops share one clock and next-state logic decides which bits toggle, so all outputs change together after one flip-flop delay. Ripple counters are smaller and lower-power; synchronous counters are used whenever outputs are decoded or speed matters.

Q24How many flip-flops are needed for a mod-N counter, and what do ring and Johnson counters give?Medium

A binary mod-N counter needs ⌈log2 N⌉ flip-flops (mod-10 needs 4). A ring counter of n flip-flops circulates a single 1 and gives n states with no decoding needed (one-hot). A Johnson (twisted-ring) counter feeds back the inverted last output and gives 2n states with n flip-flops; each state is decoded with a single 2-input gate. An n-bit maximal-length LFSR gives 2n − 1 states and is used for pseudo-random sequences and BIST.

Finite state machines

Q25What is the difference between Moore and Mealy machines?Easy

MooreMealy
Output depends onCurrent state onlyCurrent state and inputs
Output timingChanges only after a clock edgeCan change as soon as input changes
States neededUsually moreUsually fewer
Glitch risk on outputLow (often registered)Higher (input glitches pass through)

A Mealy output reacts one cycle earlier for the same behaviour. If you need a clean, registered output, use Moore or register the Mealy output.

Q26Design a Moore FSM that detects the sequence 1011 with overlap. How many states?Medium

Five states, named after the longest prefix of 1011 seen so far:

StateMeaningInput 0 →Input 1 →Output
S0nothingS0S10
S1"1"S2S10
S2"10"S0S30
S3"101"S2S40
S4"1011" (detected)S2S11

Overlap is handled by the transitions out of S4: after 1011, the trailing "1" is a valid start, so a 1 goes to S1 and a 0 gives "10" and goes to S2. A Mealy version needs only 4 states.

Timing: setup, hold, metastability

Q28Define setup time, hold time and clock-to-Q delay.Easy

Setup time (tsu): the minimum time the D input must be stable before the active clock edge. Hold time (th): the minimum time D must stay stable after the edge. Clock-to-Q (tcq): the delay from the clock edge until Q shows the new value. Violating setup or hold can make the flip-flop go metastable or capture a wrong value.

Q29Write the setup and hold constraints for a path between two flip-flops.Medium

For a launch flip-flop and a capture flip-flop with combinational delay between them, clock period T and clock skew tskew (capture clock later than launch clock is positive):

Setup: tcq + tcomb,max + tsu ≤ T + tskew
Hold: tcq + tcomb,min ≥ th + tskew

Maximum frequency is fmax = 1 / (tcq + tcomb,max + tsu − tskew). Example: tcq = 0.3 ns, tcomb = 3.5 ns, tsu = 0.2 ns, no skew → Tmin = 4 ns, fmax = 250 MHz.

Q30Why can't you fix a hold violation by slowing down the clock?Medium

The hold constraint does not contain the clock period T. Hold checks whether new data, launched by an edge, races through and corrupts the data being captured by the same edge at the next flip-flop. Changing the period moves the next edge, not the current one. Hold violations are fixed by adding delay to the short path (buffers), reducing skew, or using flip-flops with smaller hold times. Setup violations, by contrast, can be fixed by slowing the clock.

Q31What is positive and negative clock skew and how does it affect setup and hold?Medium

Skew is the difference in clock arrival time at two flip-flops. Positive skew (capture clock arrives later than launch) gives the data more time, helping setup but hurting hold. Negative skew helps hold and hurts setup. This is why clock tree synthesis aims for low skew, and why useful skew is sometimes added deliberately to borrow time for a critical path.

Q32What is metastability?Medium

If a flip-flop's input changes inside its setup–hold window, the internal cross-coupled latch can settle at an intermediate voltage for an unpredictable time before resolving to 0 or 1. The probability of still being unresolved decays exponentially with time: P ∝ e−t/τ, where τ is a device constant. It cannot be eliminated, only made extremely unlikely. It mainly arises when signals cross between unrelated clock domains or come from asynchronous inputs like buttons.

Q33How does a two-flip-flop synchroniser work, and what is MTBF?Hard

The asynchronous signal goes into flip-flop 1; its output goes into flip-flop 2 in the destination clock domain. If FF1 goes metastable, it has almost one full clock period to resolve before FF2 samples it, which makes the chance of FF2 seeing an unresolved value extremely small.

MTBF = etr/τ / (T0 · fclk · fdata)

tr is the resolution time allowed, and T0 and τ are flip-flop constants. Because tr is in an exponent, one extra stage (3-FF synchroniser) multiplies MTBF enormously; this is used at high frequencies. A two-FF synchroniser is only safe for single-bit signals. Multi-bit buses need Gray-coded pointers (async FIFO), a handshake, or a MUX-recirculation scheme so that bits do not get sampled from different cycles.

Q34How do you pass a short pulse from a fast clock domain to a slow one?Hard

A pulse shorter than the destination clock period may fall between two sampling edges and be missed completely. Options: (1) toggle synchroniser: convert the pulse into a level toggle in the source domain, synchronise the level with 2 flip-flops, then detect the edge with an XOR in the destination domain; (2) stretch the pulse in the source domain until it is at least 1.5 destination periods wide; (3) use a request–acknowledge handshake if pulses can come back to back. The toggle method is the most common answer.

CMOS and logic families

Q35Draw a CMOS inverter and explain why its static power is near zero.Easy

A PMOS from VDD to the output and an NMOS from the output to ground, gates tied to the input. For input 0, PMOS is on and NMOS off: output is VDD. For input 1, the reverse. In either steady state one transistor is off, so there is no path from VDD to ground and only leakage current flows. Power is consumed mainly while switching.

Q36Write the dynamic power equation of CMOS and ways to reduce it.Medium

Pdyn = α · CL · VDD2 · f

α is the activity factor (fraction of cycles the node switches), CL the switched capacitance and f the clock frequency. Because VDD is squared, lowering supply voltage is the strongest lever (DVFS). Other techniques: clock gating (reduce α and f in idle blocks), operand isolation, reducing capacitance by smaller or fewer gates, and multi-voltage domains. Short-circuit power during transitions and leakage power (sub-threshold, gate, junction) add to the total; leakage is handled with power gating and high-Vth cells.

Q37Why is the PMOS in a CMOS inverter made wider than the NMOS?Medium

Hole mobility in silicon is about 2–3 times lower than electron mobility, so a PMOS of the same size has a higher on-resistance. To get equal rise and fall times (and a switching threshold near VDD/2), the PMOS is sized about 2–3 times wider. In a NAND gate the NMOS are in series, so they are widened; in a NOR the PMOS are in series and must be very wide, which is why NAND is preferred.

Q38What are noise margins?Medium

Noise margin is how much noise a logic signal can tolerate before the next gate misreads it.

NMH = VOH − VIH, NML = VIL − VOL

VOH/VOL are the guaranteed output levels of the driving gate; VIH/VIL are the input levels the receiving gate accepts as 1/0. CMOS has large noise margins because its outputs swing almost rail to rail.

Q39What is latch-up in CMOS and how is it prevented?Hard

The n-well, p-substrate and the diffusions form a parasitic PNPN (thyristor) structure: a vertical PNP and a lateral NPN connected in a positive-feedback loop. A transient (supply spike, ESD, or an I/O pin driven beyond the rails) can trigger it, creating a low-resistance path from VDD to ground that persists until power is removed and can destroy the chip. Prevention: plenty of well and substrate taps (lower the well resistances), guard rings around I/O transistors, larger spacing between NMOS and PMOS, epitaxial or SOI substrates, and clamp diodes on I/O pins.

Q41What is fan-out?Medium

Fan-out is the number of gate inputs that one output can drive while still meeting its logic levels (DC fan-out) or its timing (AC fan-out). In TTL, DC fan-out is limited by current: a 74LS output can sink 8 mA and each LS input needs 0.4 mA, so fan-out is 20. In CMOS, DC fan-out is very large because inputs draw no current, but each input adds capacitance, so delay grows with fan-out. High-fan-out nets like clocks and resets are buffered in trees.

How to prepare

Digital is the most predictable part of a core-electronics interview: the same twenty ideas come back in different forms. What separates candidates is speed and clean reasoning on timing questions.

  1. Drill conversions and two's complement until they take seconds. Written tests use them as quick-score items.
  2. Solve K-maps on paper with don't-cares, and practise implementing functions with a mux and with only NAND gates.
  3. Write one FSM a day: sequence detectors (with and without overlap), traffic lights, vending machines. Draw the state table before the diagram.
  4. Learn the setup/hold equations by derivation, not memory: draw two flip-flops, the clock, and mark launch and capture edges. Every timing question is this picture.
  5. Know clock domain crossing (synchronisers, Gray pointers, toggle synchroniser). This is the most common "hard" digital question for VLSI and FPGA roles.
  6. Pair this page with Verilog. Interviewers often ask you to code the circuit you just drew.
